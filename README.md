# Devin Bay

This project is a simple e-shoping web application powered by next.js that helps users and seller work efficiently for buying and selling. I built it to practice full-stack development and improve productivity tools..

# Features

Its the initial version of devin-bay and some of features are :- 

User authentication (mongo db)
Real-time updates (uploading new products)
Dark UI to work with 

# Tech 

Frontend (HTML, React, tailwind css)
Backend ( Node.js, Next.js)
Database: (MongoDB)

# Installation

Repo clone :
```bash
git clone https://github.com/kevinhamza/Devin-Bay.git
cd Devin-Bay
npm install
npm start
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
